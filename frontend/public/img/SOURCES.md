# Fuentes de imágenes

Las 24 fotografías de catálogo fueron creadas específicamente para NoSQL Wear mediante Figma Make, con una dirección de arte común y sin marcas ni logotipos. Los archivos se almacenan localmente para que la interfaz no dependa de servicios externos.

Las imágenes `categoria-*.jpg` son copias locales de una prenda representativa de cada categoría y se utilizan únicamente como fallback.
